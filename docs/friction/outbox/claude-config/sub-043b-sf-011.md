# An executor reverted a mutation with git checkout and lost its uncommitted work

## What happened

During a port the work is uncommitted, so `git checkout --` restores the OLD
implementation. The executor recovered in one command and switched to copy-
out/copy-back with a checksum.

## Suggested direction

Executor template: revert mutations and negative controls by copy-back plus
checksum; never overlap them with a gate that builds from the working tree.
