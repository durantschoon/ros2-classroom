# Integration-branch mode is assumed by practice but not described in the skill

## What happened

The user wanted the whole effort off the default branch until done. The skill
says 'default branch' throughout; claude-config's own README already adapts
this ('the integration branch named in the launch message'), but the skill text
does not.

## Suggested direction

A short integration-branch section: prompts, bases and merges use it; sync the
default branch into it at each merge; promotion is the user's act, by merge
commit.
