# Outbox: submissions for `claude-config`

Lessons learned in this repository about the user's skills and agents, whose
source is `github.com/durantschoon/claude-config`. This session is a
**contributing author**: it writes here and nowhere else. The curator is
whichever session coordinates `claude-config`; only that session writes to it.

One file per submission, so any number of authors can add files without ever
conflicting. Each carries its provenance, its evidence, and an occurrence
count, because several authors will report the same thing and that should
raise a count, not add a row.

`kind` follows log-friction's design gate: a **symptom** may be staged
directly; a **mechanism** is a proposal and needs a design session first. The
proposals here were written against an older `SKILL.md`; treat them as intent,
not as text to paste. Fuller wording and the story behind each is in
[`docs/stages/SKILL-FEEDBACK.md`](../../../stages/SKILL-FEEDBACK.md), by `ref`.

**For the curator.** Triage each file into `claude-config`'s friction log,
choosing `type`, `maps to` and `bucket` there. Then set its `status` here to
`accepted <fr-id>`, `merged-into <fr-id>`, or `declined <why>`, so this
repository can see what became of it. Authors never choose their own bucket.
