# Coordinator test payloads were wrong in 3 of 4 stages

## What happened

Prompts contained a negative control that could not fail at the prompt's own
severity, a 'remove the tool from PATH' command that left the tool on PATH, and
an example of 'input the old code missed' that the old code matched. Executors
caught all three. After adopting 'run every payload before committing the
prompt', stages 05 and 06 had none, and the stage 05 prototype caught a harness
flaw before launch.

## Suggested direction

Add to the Author step: run every negative control, example and command in a
prompt before committing it; prototype novel approaches and quote the
measurement.
